# 動画制作フローの中での jigoe

AI で巻き取れる工程と、人が残すべき工程を整理したものです。
jigoe が担当するのは ④ ナレーション音声だけですが、
**④ で人が残すべき部分**を機能として持たせています。

| 工程 | AI 代替度 | 人が担当すべきこと |
|---|---|---|
| ① 企画・ネタ選定 | 70% | どのネタを自分の視点で語るかの選別 |
| ② リサーチ・裏取り | 40% | **スタッツ・記録・移籍の一次ソース確認** |
| ③ 台本・構成 | 75% | 自分の意見・体験・語り口の注入 |
| ④ ナレーション音声 | 95% | **固有名詞の誤読チェック／重要箇所の「間」** |
| ⑤ 画像・素材 | 60% | **著作権処理、動画ごと最低 1 点の独自図解** |
| ⑥ 編集 | 70% | 字幕の誤変換修正、映像と音声の一致 |
| ⑦ サムネイル | 65% | 文言・構図の判断、肖像権の回避 |
| ⑧ メタデータ | 85% | クレジット表記、誇大表現の回避 |
| ⑨ 投稿・分析 | 50% | 数値を見た方針転換 |

事故が起きやすいのは **② の裏取り・④ の誤読・⑤ の著作権** の 3 点です。

---

## jigoe が ④ で担当していること

### 誤読チェック（人の担当を機械が並べる）

`jigoe check` は、読み辞書に未登録の固有名詞・スコア・小数を列挙します。
判断するのは人ですが、**どこを見ればいいかを漏れなく出す**のは機械の仕事です。

```bash
jigoe check scripts/ep01.txt --strict   # 未確認が残っていれば終了コード 2
```

CI や投稿前のチェックリストに組み込めば、誤読のまま公開する事故が防げます。

### 「間」の調整

重要な一言の前に 0.3〜0.8 秒の無音を置くと、視聴維持率に効きます。
これは合成エンジンには判断できないので、台本側に残します。

```
その名はピストル・ピート。[[0.8]]NBAが彼を受け入れるには、20年早すぎました。
```

---

## jigoe が担当しないこと

- **② 事実確認**: 年号・スタッツ・移籍はツールでは検証できません。
  公式サイト（NBA 公式、Basketball-Reference 等）で必ず裏を取ってください。
- **⑤ 画像の著作権**: ネット画像の無断使用は原則 NG です。特に選手写真は
  撮影者の著作権・パブリシティ権・リーグの商標が多重にかかります。
  AI 生成 ＋ 商用可素材 ＋ 自作図解の組み合わせが、著作権と収益化ポリシーの
  両面で安全です。
- **③ 独自性の注入**: 既存情報の再構成だけのコンテンツは、収益化ポリシー上
  不利になります。自分の視点・体験を台本に入れるのは人の仕事です。

## 台本から投稿までの流れ（例）

```bash
# 1. 台本を書く（AI と壁打ちしてもよいが、事実は自分で裏を取る）
vim scripts/ep01.txt

# 2. 誤読チェック。出てきた固有名詞の読みを辞書に登録する
jigoe check scripts/ep01.txt
jigoe lexicon scan scripts/ep01.txt -o lexicon/ep01.tsv
vim lexicon/ep01.tsv                    # 読みの列を埋める

# 3. 未確認がゼロになったら合成
jigoe check scripts/ep01.txt --strict && jigoe speak scripts/ep01.txt

# 4. out/ に出たものを編集ソフトへ
#    ep01.wav        → タイムラインに配置
#    ep01.srt        → 字幕として読み込む（自動字幕より正確）
#    ep01.chapters.txt → 概要欄に貼る
```

台本を直したら `jigoe speak` をもう一度実行するだけです。
変わっていない文はキャッシュから再利用されるので、クラウド API の
クレジットは変更分にしか使われません。
