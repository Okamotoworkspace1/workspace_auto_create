# オープニング

NBAで歴代最強のチームはどこか。[[0.7]]この質問には、いちおう決着がついています。

1995年から96年の、シカゴ・ブルズ。[[0.5]]レギュラーシーズン、72勝10敗。

ただ、ここで一つ引っかかることがあります。

@pause 0.8

この記録、すでに破られているんです。[[0.6]]2016年のゴールデンステート・ウォリアーズが、73勝しました。

にもかかわらず、歴代最強と呼ばれているのは、いまだにブルズのほうです。[[0.8]]なぜか。

その理由は、72という数字の中にはありません。

# すべては、負けた次の年だった

話は前の年、1995年の春から始まります。

マイケル・ジョーダンは、野球から戻ってきたばかりでした。[[0.5]]背番号は、23ではなく45。

1年半ぶりのコートで、彼は明らかに、かつての彼ではありませんでした。

プレーオフの相手は、オーランド・マジック。[[0.4]]第1戦の終盤、ジョーダンはボールを運びながら、背後から手を出されます。

ニック・アンダーソン。[[0.5]]そのスティールが決勝点につながり、ブルズは落としました。

@speed 0.95

試合後、アンダーソンはこう言ったと伝えられています。[[0.6]]「45番は、23番のようには爆発しない」。

@speed reset

ジョーダンはシリーズの途中で背番号を23に戻しますが、ブルズはこのシリーズに敗退します。

@pause 1.0

72勝10敗のシーズンは、[[0.4]]この負けの、次の年の話です。

# 問題児を、あえて獲る

そのオフ、ブルズがやったことは、補強としてはかなり乱暴でした。

デニス・ロッドマンの獲得です。

リバウンド王。[[0.5]]同時に、審判に暴言を吐き、監督と衝突し、前の年にはチームから持て余されていた選手でした。

しかもこの男、元デトロイト・ピストンズです。[[0.6]]バッドボーイズの一員として、90年代の初めにブルズを痛めつけていた側でした。

スコッティ・ピッペンは、かつてロッドマンに突き飛ばされて流血しています。[[0.8]]チームメイトとして、最も相性が悪そうな相手です。

ブルズは、それを承知で獲りました。

@speed 0.97

このとき球団は、獲得の前にジョーダンとピッペンに直接意見を聞いた、と言われています。[[0.6]]ロッカールームを壊す可能性のある選手だったからです。

@speed reset

二人は、受け入れました。[[0.5]]勝てるなら、という条件つきで。

@pause 0.9

結果、ロッドマンはこのシーズン、平均14.9リバウンド。[[0.5]]5年連続のリバウンド王です。

得点は、求められていません。[[0.4]]ジョーダンとピッペンが点を取るので、彼の仕事は、外れたシュートを拾うことだけでした。

役割を極端に絞れば、問題児は戦力になる。[[0.6]]このチームが証明したのは、そういうことでもあります。

# 72勝の中身

シーズンが始まると、ブルズは開幕から44試合を、41勝3敗で終えます。

ホームでの成績は、39勝2敗。[[0.6]]シカゴのユナイテッド・センターは、ほぼ負けない場所でした。

そしてこのシーズン、ブルズは一度も3連敗をしていません。[[0.8]]82試合を通して、連敗は最大でも2つ。

強いチームは、勝ちが続きます。[[0.4]]ただ、負けが続かないというのは、また別の強さです。

ジョーダン本人は、平均30.4点で得点王。[[0.5]]32歳のシーズンでした。

野球から戻って2年目に、彼はもう一度リーグで一番点を取る選手に戻っています。

# 主役以外が、異常に強い

このチームを「ジョーダンのチーム」とだけ呼ぶと、たぶん本質を外します。

@speed 0.97

スティーブ・カー。[[0.4]]このシーズン、スリーポイントの成功率が5割を超えています。

トニー・クーコッチ。[[0.5]]ベンチから出て、シックスマン賞。

ロン・ハーパー。[[0.4]]かつては平均20点を超える得点源だった選手が、ブルズでは守備担当に回りました。

@speed reset

そして、テックス・ウィンターのトライアングル・オフェンス。[[0.6]]ボールを一人に集めず、三角形の位置関係でパスを回し続ける仕組みです。

史上最高の得点者を抱えたチームが、[[0.4]]一人に頼らないための戦術を採用していた。[[0.7]]ここが、このチームの不思議なところです。

フィル・ジャクソンは、このシーズンの最優秀コーチに選ばれています。

# 父の日のファイナル

ファイナルの相手は、シアトル・スーパーソニックス。

ソニックスには、ショーン・ケンプとゲイリー・ペイトンがいました。

ブルズは3連勝で王手をかけますが、[[0.5]]そこから2つ落とします。

@speed 0.97

きっかけは、マッチアップの変更でした。[[0.4]]ソニックスが、ペイトンをジョーダンに当て始めたんです。

@speed reset

リーグ最高の守備的ガードを一人ぶつける。[[0.6]]それでようやく、2つ返せた。[[0.5]]この年のブルズを止めるには、それくらいが必要だったということでもあります。

第6戦。[[0.4]]1996年6月16日、シカゴでの試合でした。

@pause 1.0

この日は、アメリカのファーザーズデー、父の日です。

ジョーダンの父、ジェームズ・ジョーダンは、[[0.5]]1993年に殺害されていました。[[0.7]]彼が一度バスケットボールを離れた理由の、ひとつと言われています。

@speed 0.93

試合終了。[[0.5]]優勝が決まった瞬間、ジョーダンはコートに残りませんでした。[[0.6]]ロッカールームの床で、ボールを抱えたまま、うずくまっていました。

@speed reset

このシーズン、ジョーダンは得点王、シーズンMVP、オールスターMVP、そしてファイナルMVP。[[0.6]]獲れるものを、ほぼ全部獲っています。

ただ、この日の映像で記憶されているのは、そこではありません。

# 72勝と73勝のあいだ

最初の質問に戻ります。

2016年のウォリアーズは、73勝しました。[[0.6]]ブルズの記録を、1つ上回っています。

ただ、そのチームはファイナルで敗れました。

@pause 0.9

一方のブルズは、プレーオフを15勝3敗で通過しています。[[0.5]]レギュラーシーズンと合わせると、87勝13敗。

@pause 0.6

ここで、両方の数字を並べてみます。

ウォリアーズは、プレーオフが15勝9敗。[[0.4]]合計、88勝18敗。[[0.6]]ブルズは、87勝13敗。

@speed 0.95

勝った試合の数だけなら、ウォリアーズのほうが多いんです。[[0.7]]違っているのは、負けた数のほうでした。

@speed reset

ブルズが1年で落とした試合は、13。[[0.6]]プレーオフに限れば、3つだけです。

歴代最強という言葉が指しているのは、たぶん勝った数ではありません。[[0.7]]取りこぼさなかった、という一点です。

@speed reset

# まとめ

前の年に負けたチームが、[[0.4]]問題児を一人足して、[[0.4]]翌年に87勝13敗で終わった。

強さの話というより、[[0.6]]負けたあとに何をしたかの話だったのかもしれません。

1995年から96年の、シカゴ・ブルズ。[[0.8]]歴代最強という称号が、30年経っても動かない理由でした。
