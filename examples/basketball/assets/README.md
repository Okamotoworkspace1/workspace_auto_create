# 素材カタログ

チャンネル全体の素材をここにまとめています。回ごとに探し直さず、`catalog.tsv` に足していく運用です。

| ファイル | 中身 |
|---|---|
| `catalog.tsv` | **素材の一覧。ラベル・タグ・年・ライセンス・URL** |
| `catalog.py` | カタログの検索 |
| `ep02_short/` | 自作した図解（探してこられないものだけ） |
| `make_ep02_short.py` | その生成スクリプト |

```bash
python3 catalog.py                  # 全件
python3 catalog.py ロッドマン        # ラベル・タグ・メモの部分一致
python3 catalog.py --no-sa          # 継承なしだけ（収益化チャンネル向き）
python3 catalog.py --kind 動画
python3 catalog.py --todo           # ライセンス未確認のものだけ
python3 catalog.py ブルズ --urls     # URL だけ
```

> **画像の実体はこのリポジトリに入っていません。**
> 作業環境から commons.wikimedia.org・Pexels・Pixabay などへの通信が
> 組織のネットワークポリシーで遮断されており、ファイルを取得できませんでした。
> カタログの URL を開いて手元で落としてください。
>
> **同じ理由で、ライセンス欄は検索結果に出ていた表示です。**
> こちらでファイルページの原本を開けていないので、初期値は全て `確認 = 未` です。
> 使う前にページを開き、**著作者名・ライセンス・現存**を確かめて `済` にしてください。
> 著作者名は推測で埋めず、ファイルページの「作者」欄をそのまま写します。

## 1. 探すときの前提

### 1995-96 シーズンの試合映像・写真は、実質的に手に入りません

当時の試合映像の著作権は NBA が持ち、Content ID に全試合分が登録されています。
写真も NBAE / Getty の管理で、エディトリアル契約は収益化 YouTube を通常カバーしません。
**「1996年ファイナルの映像を貼る」は選択肢から外してください。**

### そのうえで、1996年の実素材が 4 点見つかっています

カタログの先頭 5 件（`--no-sa` で出るもの）がそれです。特に次の 3 点は当たりです。

| 素材 | なぜ良いか |
|---|---|
| **ホワイトハウス訪問の写真** | 1996年優勝メンバーが一枚に収まる。ジョーダン・ロッドマン・ピッペン・ジャクソンが同じ画に |
| **同・映像（webm）** | 自由に使える「動く1996年ブルズ」。パブリックドメイン表示 |
| **第6戦 公式スコアラーズレポート** | 当日のボックススコア。選手写真より強い一次資料 |

ホワイトハウスのものは米政府職員の職務著作＝パブリックドメインの扱いで、
**帰属義務も継承もありません。** ライセンス根拠の確認だけは必ずしてください。

### CC BY-SA を動画に入れると、動画側にも継承が及ぶ可能性があります

カタログの「継承 = あり」がそれです（Lipofsky 氏のジョーダン、カリー、
ユナイテッド・センターなど）。画像を動画に組み込んだものが「二次的著作物」と
評価されると、**動画全体を同じ CC BY-SA で公開する義務**が生じ得ます。
解釈が割れており、判例で固まってはいません。

収益化チャンネルで避けたいなら、選択肢は次のどれかです。

1. **使わない。** `catalog.py --no-sa` の範囲＋自作図解で組む（既定）
2. **継承を受け入れる。** 概要欄で動画を CC BY-SA として明示する
3. **権利者から直接ライセンスを得る。** Lipofsky 氏は自身のサイト
   （basketballphoto.com）で写真をライセンスしています。個別交渉が最も安全

**法務リスクの取り方なので、こちらでは決められません。**

### ロゴは商標です

`シカゴ・ブルズ ロゴ` などは Commons にありますが、ライセンス表記が緩くても
商標・パブリシティの問題が残ります。サムネイルでの使用は特に避けてください。

### 年代のズレ

自由ライセンスのジョーダンは **1987年と1997年**、ロッドマンは **2001年以降**が中心です。

- ジョーダンの 1997 年はユニフォームが同世代なので **そのまま使えます**
- ロッドマンの引退後写真を「1995年に加入した問題児」として出すのは**無理があります**。
  ホワイトハウスの集合写真から抜くか、b-roll で逃げてください
- 写真の年が問題になりそうなら、テロップで「写真は1997年」と添えると事故になりません

| 0:30-0:43 | 87-13 と 88-18 | `fig-ep02-wins` |

## 3. クレジット（概要欄に貼る）

CC BY-SA は**著作者名・ライセンス名・ライセンスへのリンク**の 3 点が必須です。
パブリックドメインのものは義務ではありませんが、出所を書くと後で追えます。

```
【画像クレジット】
1996 Chicago Bulls at the White House — White House photo / Wikimedia Commons — Public Domain
Official Scorer's Report, 1996 NBA Finals Game 6 — Wikimedia Commons
Michael Jordan (1997) — Steve Lipofsky / Wikimedia Commons — CC BY-SA 3.0
  https://creativecommons.org/licenses/by-sa/3.0/
Stephen Curry (2016) — <ファイルページ記載の著作者> / Wikimedia Commons — CC BY-SA 2.0
  https://creativecommons.org/licenses/by-sa/2.0/

b-roll: Pexels / Pixabay
図解: 本チャンネル制作（出典 Basketball-Reference）
```

## 4. 自作した 5 点

数字の図解は探してこられないので、ここだけ自作しています。
`docs/workflow.md` が求める「動画ごと最低 1 点の独自図解」も兼ねます。

```bash
python3 make_ep02_short.py --png
JIGOE_FONT="Noto Sans JP" python3 make_ep02_short.py --png   # フォントを差し替える
```

- 1080×1920。内容はセーフエリア（x 80-880 / y 200-1480）に収めてあります
- 配色は青と赤の 2 色。色覚多様性を検証済み（CVD ΔE 19.2、全チェック PASS）で、
  かつ**色だけに意味を持たせず全ての棒に直接ラベル**を置いています
- 棒はゼロ基点です。72 と 73 の差が小さく見えるのは事実どおりで、そこが要点です
- SVG が原本なので、フォント・文言はテキストエディタで直せます

## 5. カタログに足すとき

`catalog.tsv` に 1 行足すだけです。列は
`ID / ラベル / タグ / 年 / 種別 / ライセンス / 継承 / URL / 確認 / メモ`。

- **タグは日本語で、カンマ区切り。** 人名・チーム・年代・用途を入れておくと後で引けます
- **継承** は `あり` / `なし` / `要確認` のどれか。`要確認` は `--no-sa` に出ません
- **確認** は原本を見るまで `未`。見たら `済`
- 年代が回の題材と合わない素材は、メモにその旨を書いておくと事故が減ります
