# 素材

**基本は実写です。** カタログの実写を先に当てて、埋まらないカットだけ生成で補います。

| ファイル | 中身 |
|---|---|
| `catalog.tsv` | 素材の一覧。ラベル・タグ・年・ライセンス・URL |
| `catalog.py` | カタログの検索 |
| `prompts/` | **埋まらないカット用の画像生成プロンプト** |
| `ep02_short/` | 自作した数字の図解 |
| `make_ep02_short.py` | その生成スクリプト |

---

## 1. カタログを引く

```bash
python3 catalog.py                  # 全件
python3 catalog.py ロッドマン        # ラベル・タグ・メモの部分一致
python3 catalog.py --kind 動画
python3 catalog.py --no-sa          # 継承なしだけ（公開前の精査用）
python3 catalog.py --todo           # ライセンス未確認のものだけ
```

`catalog.tsv` に 1 行足すだけで増やせます。列は
`ID / ラベル / タグ / 年 / 種別 / ライセンス / 継承 / URL / 確認 / メモ`。

- **タグは日本語でカンマ区切り。** 人名・チーム・年代・用途を入れると後で引けます
- **継承** は `あり` / `なし` / `要確認`。`要確認` は `--no-sa` に出ません
- **確認** は原本を見るまで `未`
- 年代が合わない素材は、メモにその旨を書いておく

回を重ねるほどカタログが育ち、新しい回で実写が当たる割合が上がります。
生成した画像も `種別 = 生成` で足しておくと使い回せます。

> **画像の実体はこのリポジトリに入っていません。**
> 作業環境から commons.wikimedia.org・Pexels などへの通信が組織のネットワーク
> ポリシーで遮断されており、取得できませんでした。URL を開いて手元で落としてください。
> ライセンス欄も検索結果の表示であり、原本を確認できていないので全件 `確認 = 未` です。

## 2. 埋まらないカットを生成で補う

`prompts/<回>.md` に、カットごとの生成プロンプトを置いています。

**生成では作れないものが 3 つあります。**

| 作れない | 理由 | どうするか |
|---|---|---|
| 実在人物 | 画像生成は実在人物の肖像を作らない。作れても肖像権が残る | カタログの実写を使う |
| チームのロゴ・ユニフォーム | 商標 | 無地で生成し、記号はテロップで足す |
| 日本語のテロップ | 文字が崩れる | 編集ソフトで乗せる |

**人物が要るカットは実写、雰囲気をつなぐカットは生成**という切り分けになります。
生成画像だけで組むと、どのチャンネルでも作れる映像になります。
実在の人物・記録を最低 2〜3 枚は混ぜてください。

## 3. 自作した図解

数字の図解だけは探してこられないので自作しています。
`docs/workflow.md` が求める「動画ごと最低 1 点の独自図解」も兼ねます。

```bash
python3 make_ep02_short.py --png
JIGOE_FONT="Noto Sans JP" python3 make_ep02_short.py --png   # フォントを差し替える
```

- 1080×1920。セーフエリア（x 80-880 / y 200-1480）に収めてあります
- 配色は青と赤。色覚多様性を検証済み（CVD ΔE 19.2）で、色だけに意味を持たせず
  全ての棒に直接ラベルを置いています
- 棒はゼロ基点。72 と 73 の差が小さく見えるのは事実どおりで、そこが要点です
- SVG が原本なので、文言はテキストエディタで直せます

## 4. 公開前に見るところ（後工程）

作っている最中は気にしなくて構いません。**公開の直前にここへ戻ってください。**

### 1995-96 シーズンの試合映像・写真は手に入りません

当時の試合映像は NBA が Content ID に全試合登録しており、写真も NBAE / Getty
管理です。そのうえで、1996年の実素材が 4 点見つかっています（`--no-sa` の上位）。

| 素材 | なぜ良いか |
|---|---|
| ホワイトハウス訪問の写真 | 1996年優勝メンバーが一枚に。米政府の職務著作＝PD 扱い |
| 同・映像（webm） | 自由に使える「動く1996年ブルズ」 |
| 第6戦 公式スコアラーズレポート | 当日のボックススコア。強い一次資料 |

### CC BY-SA は動画側にも継承が及び得ます

カタログの「継承 = あり」がそれです。画像を動画に組み込んだものが二次的著作物と
評価されると、動画全体を同じ CC BY-SA で公開する義務が生じ得ます。解釈が割れており、
判例で固まってはいません。避けるなら `catalog.py --no-sa` の範囲で組み直します。

### そのほか

- **ロゴは商標**です。ライセンス表記が緩くてもサムネイルでの使用は避ける
- **年代のズレ**：自由ライセンスのジョーダンは 1987年と1997年。1997年は
  ユニフォームが同世代なので使えます。引退後のロッドマンを1995年の文脈に出すのは無理があります
- **クレジット**：CC BY-SA は著作者名・ライセンス名・リンクの 3 点が必須です
