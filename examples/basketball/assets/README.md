# 素材カタログと絵コンテ

**まず全カットを埋める。精査は後。** 回を重ねるほどカタログが育ち、
新しい回で埋まる割合が上がっていく作りにしてあります。

| ファイル | 中身 |
|---|---|
| `catalog.tsv` | 素材の一覧。ラベル・タグ・年・ライセンス・URL |
| `keywords.tsv` | **キーワード → 素材ID の既定割り当て**（全回共通） |
| `keywords.<回>.tsv` | 回ごとの割り当て。自作図解はここに置く |
| `storyboard.py` | 台本から絵コンテを自動生成 |
| `catalog.py` | カタログの検索 |
| `shots/` | 生成された絵コンテ |
| `ep02_short/` ほか | 自作した図解 |

---

## 1. 回を 1 本作る流れ

```bash
jigoe speak scripts/ep03.txt                          # 音声と report.json を作る
python3 assets/storyboard.py out/ep03.report.json -o assets/shots/ep03.md
```

これだけで、台詞ごとに素材が当たった絵コンテが出ます。

```
| 0:54-0:56 | ジョーダンが野球から戻って、 | ジョーダン フリースローライン `ジョーダン` | 開く |
```

「ジョーダン」と出たら MJ の画像が 1 枚当たる、という単純な仕組みです。
**合っているかは完成品を見てから直せばいい**ので、まず全部埋めます。

### 埋まらなかったところ

絵コンテの末尾に「キーワードが当たったカット: 16 / 21」と出ます。
残りは受け皿（b-roll）です。埋めたければ次のどちらかを足します。

1. `keywords.tsv` に語を足す（既にある素材を割り当てる）
2. `catalog.tsv` に素材を足してから 1 をやる

ep01（マラビッチ）が 7/17 と低いのは、その年代の素材がまだ少ないからです。
**カタログが育てば、過去回も作り直さずに再生成するだけで良くなります。**

### 素材を差し替えたいとき

`keywords.tsv` の素材ID を書き換えて `storyboard.py` を再実行するだけです。
絵コンテは毎回まるごと作り直されるので、手で直した内容は残りません。
**直すのは台本かキーワード表のほう**、という運用にしてください。

### 回ごとの割り当てを分ける理由

自作図解は回ごとの絵なので、共通表に入れると他の回に混入します
（実際に ep01 にブルズの棒グラフが出ました）。回固有のものは
`keywords.ep02.tsv` のように分けてください。`ep02_short` の絵コンテは
`keywords.ep02_short.tsv` → `keywords.ep02.tsv` → `keywords.tsv` の順に読まれます。

### 1 カットの長さ

同じ素材が続く区間はひとつのカットにまとめますが、**8 秒で切り直します**
（`storyboard.py` の `MAX_SHOT_SECONDS`）。受け皿が続くと
30 秒 1 枚のような絵コンテになるためです。

## 2. カタログを育てる

```bash
python3 catalog.py                  # 全件
python3 catalog.py ロッドマン        # ラベル・タグ・メモの部分一致
python3 catalog.py --kind 動画
python3 catalog.py --no-sa          # 継承なしだけ（公開前の精査用）
python3 catalog.py --todo           # ライセンス未確認のものだけ
```

`catalog.tsv` に 1 行足すだけです。列は
`ID / ラベル / タグ / 年 / 種別 / ライセンス / 継承 / URL / 確認 / メモ`。

- **タグは日本語でカンマ区切り。** 人名・チーム・年代・用途を入れると後で引けます
- **継承** は `あり` / `なし` / `要確認`。`要確認` は `--no-sa` に出ません
- **確認** は原本を見るまで `未`
- 年代が合わない素材は、メモにその旨を書いておく

> **画像の実体はこのリポジトリに入っていません。**
> 作業環境から commons.wikimedia.org・Pexels などへの通信が組織のネットワーク
> ポリシーで遮断されており、取得できませんでした。URL を開いて手元で落としてください。
> ライセンス欄も検索結果の表示であり、原本を確認できていないので全件 `確認 = 未` です。

## 3. 公開前に見るところ（後工程）

作っている最中は気にしなくて構いません。**公開の直前にここへ戻ってきてください。**

### 1995-96 シーズンの試合映像・写真は手に入りません

当時の試合映像は NBA が Content ID に全試合登録しており、写真も NBAE / Getty
管理です。そのうえで、1996年の実素材が 4 点見つかっています（`--no-sa` の上位）。

| 素材 | なぜ良いか |
|---|---|
| ホワイトハウス訪問の写真 | 1996年優勝メンバーが一枚に。米政府の職務著作＝PD 扱い |
| 同・映像（webm） | 自由に使える「動く1996年ブルズ」 |
| 第6戦 公式スコアラーズレポート | 当日のボックススコア。強い一次資料 |

### CC BY-SA は動画側にも継承が及び得ます

カタログの「継承 = あり」がそれです。画像を動画に組み込んだものが二次的著作物と
評価されると、動画全体を同じ CC BY-SA で公開する義務が生じ得ます。解釈が割れており、
判例で固まってはいません。避けるなら `catalog.py --no-sa` の範囲で組み直します。

### そのほか

- **ロゴは商標**です。ライセンス表記が緩くてもサムネイルでの使用は避ける
- **年代のズレ**：自由ライセンスのジョーダンは 1987年と1997年。1997年は
  ユニフォームが同世代なので使えます。引退後のロッドマンを1995年の文脈に出すのは無理があります
- **クレジット**：CC BY-SA は著作者名・ライセンス名・リンクの 3 点が必須。
  絵コンテの末尾に「使った素材」の表が出るので、そこから概要欄を作れます

## 4. 自作した図解

数字の図解だけは探してこられないので自作しています。
`docs/workflow.md` が求める「動画ごと最低 1 点の独自図解」も兼ねます。

```bash
python3 make_ep02_short.py --png
JIGOE_FONT="Noto Sans JP" python3 make_ep02_short.py --png   # フォントを差し替える
```

- 1080×1920。セーフエリア（x 80-880 / y 200-1480）に収めてあります
- 配色は青と赤。色覚多様性を検証済み（CVD ΔE 19.2）で、色だけに意味を持たせず
  全ての棒に直接ラベルを置いています
- 棒はゼロ基点。72 と 73 の差が小さく見えるのは事実どおりで、そこが要点です
- SVG が原本なので、文言はテキストエディタで直せます
