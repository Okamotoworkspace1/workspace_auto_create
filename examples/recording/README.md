# 収録原稿について

`収録原稿.txt` は、自分の声のモデルを学習させるために読み上げる原稿です。
ITAコーパス（<https://github.com/mmorise/ita-corpus>・パブリックドメイン）の
424 文を、番号付きでそのまま読める形に整えたものです。

## 使い方

1. `収録原稿.txt` を開く
2. 録音を開始し、**止めずに通しで**読む（番号は読まない）
3. WAV 形式で保存する
4. [Style-Bert-VITS2 の Colab](https://colab.research.google.com/github/litagin02/Style-Bert-VITS2/blob/master/colab.ipynb)
   にアップロードして学習させる

長い音声は Style-Bert-VITS2 側で自動的にスライス・書き起こしされるので、
**1 文ずつファイルを分ける必要はありません。**

## なぜこの文章なのか

ITAコーパスは、日本語の音（モノフォン・ダイフォン・トライフォン）を
偏りなく含むように設計された文集です。ふだん言わないような文が混ざるのは
そのためで、これを読んでおくと、**学習後にどんな台本を渡しても
破綻しにくい**モデルになります。

自分のチャンネルの台本を読んだ音声を足すと、さらに用途に合った声になります。
その場合も、同じ日・同じ環境・同じトーンで録ってください。

## 量の目安

| 読む範囲 | おおよその収録時間 | 位置づけ |
|---|---|---|
| 1〜150 | 約 12 分 | 学習できる最低ライン |
| 1〜300 | 約 25 分 | 品質が安定する |
| 1〜424 | 約 35 分 | いちばん良い結果になる |

途中でやめても構いません。あとから追加で録って足せます。
