# YouTube ダウンローダー（Mac 用）

YouTube の URL を**コピーして ⌘V するだけ**で、**動画（MP4）** か **音声（MP3）** として保存できるアプリです。

- 🎬 **MP4**：QuickTime Player や写真アプリでそのまま再生できる形式（H.264）を優先して保存
- 🎵 **MP3**：音声だけを取り出して保存（128 / 192 / 320 kbps）
- 📋 **貼るだけで開始**：画面のどこで ⌘V しても受け付け、すぐにダウンロードを始めます。
  リンクのドラッグ＆ドロップ、文章ごとの貼り付け、複数の URL の一括貼り付けにも対応
- 📑 **順番待ち**：何本でも追加でき、1 本ずつ順に保存。途中でキャンセル・失敗したものは再試行も可能
- 🔔 **通知**：終わったら Mac の通知でお知らせ。一覧の「▶︎ 再生」「Finder で表示」ですぐ開けます
- 💾 **覚えておく**：形式・画質・保存先・ダウンロード履歴は、次に開いたときもそのまま
- 🚪 **閉じれば終わる**：ブラウザのタブを閉じると、ダウンロードが済みしだいアプリも自動で終了します

> ⚠️ 著作権者が保存を認めている動画（ご自身の動画、クリエイティブ・コモンズの動画など）にだけ使ってください。
> YouTube の利用規約では、許可なくダウンロードすることを原則として禁止しています。

## はじめかた（最初の 1 回だけ）

1. Finder で `ytdl` フォルダを開き、**`アプリを作る.command`** をダブルクリックします。
   - 「開発元を確認できない」と表示されたら、ファイルを **右クリック（control + クリック）→「開く」** を選んでください。
2. 「アプリケーション」フォルダに **YouTubeダウンローダー** ができて、そのまま起動します。
3. 必要なソフト（Python・ffmpeg）が入っていなければ案内が出ます。「準備する」を押すと
   ターミナルが開いて自動でインストールされます。終わったらアプリをもう一度開いてください。
   - Homebrew も無い場合は一緒にインストールします。途中で Mac のログインパスワードを聞かれます。
4. 初回だけ、部品のダウンロードに 1〜2 分かかります（通知が出ます）。

これで準備完了です。以降は **Launchpad** や **Spotlight（⌘ + スペース →「YouTube」）** から開けます。
Dock に置いておくとさらに便利です。

## 使い方

1. アプリを開くと、ブラウザに画面が出ます。
2. 「🎬 動画 MP4」か「🎵 音声 MP3」を選びます（前回の選択を覚えています）。
3. YouTube で動画の URL をコピーし、画面で **⌘V**。それだけでダウンロードが始まります。
4. 保存先は `~/Downloads/YouTube`。「変更…」で好きなフォルダを選べます。

| やりたいこと | 方法 |
|---|---|
| まとめて保存したい | URL を何行でもまとめて貼り付け。順番に保存されます |
| 画質を選んでから始めたい | 「貼り付けたらすぐダウンロード」を外すと、貼った URL が欄に入るだけになります |
| 終了したい | タブを閉じるか、右上の「終了」 |
| 同じ動画をもう一度保存した | 上書きせず「〜 (2).mp4」のように別名で保存します |

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| 「この動画の形式を取得できませんでした」 | YouTube 側の仕様変更です。アプリを一度終了して開き直すと部品が最新になり、たいてい直ります |
| 「YouTube に一時的に制限されています」 | 短時間に大量に保存すると起きます。しばらく待ってから「再試行」 |
| 「年齢制限」「メンバー限定」「非公開」 | ログインが必要な動画は保存できません |
| 最高画質の MP4 が QuickTime で再生できない | H.264 版が無い動画です。VLC で再生するか、画質を「1080p まで」などにして保存し直してください |
| アプリを開いても何も起きない | `~/Library/Application Support/YouTubeDownloader/launcher.log` にエラー内容が残っています |
| アプリのフォルダを移動した | アプリは中に必要なものを持っているので、そのまま動きます |

エラーの「くわしく」を開くと、元の英語のエラーメッセージを確認できます。

## ターミナルから使う

アプリにしなくても、`YouTubeダウンローダー.command` をダブルクリックすればターミナル経由で同じ画面が開きます。
URL を渡すと画面を出さずに保存します。

```bash
cd ytdl
./YouTubeダウンローダー.command "https://www.youtube.com/watch?v=XXXXXXXXXXX"          # MP4
./YouTubeダウンローダー.command "https://youtu.be/XXXXXXXXXXX" --mp3                   # MP3
./YouTubeダウンローダー.command URL1 URL2 URL3 -q 720 -o ~/Movies                      # 複数・720p まで・保存先指定
```

| オプション | 内容 |
|---|---|
| `--mp3` | 音声だけを MP3 で保存（省略すると MP4） |
| `-q`, `--quality` | MP4: `best` / `1080` / `720` / `480`（既定 `best`）<br>MP3: `320` / `192` / `128`（既定 `192`） |
| `-o`, `--output` | 保存先フォルダ（既定 `~/Downloads/YouTube`） |
| `--port` | 画面のポート番号（既定は 8765、使えなければ空き番号） |
| `--no-browser` | 画面モードでブラウザを自動で開かない |

## 更新・削除

- **更新**：このフォルダの `ytdl_app.py` を新しくしたら、`アプリを作る.command` をもう一度実行してください。
  なお、ダウンロード部品（yt-dlp）はアプリが 1 日 1 回自動で最新にします。
- **削除**：「アプリケーション」の YouTubeダウンローダー と、
  `~/Library/Application Support/YouTubeDownloader`（設定・履歴・部品）をゴミ箱へ。
  保存した動画は消えません。

## しくみ

| ファイル | 役割 |
|---|---|
| `ytdl_app.py` | 本体。画面（Python 標準ライブラリだけのローカルサーバー）とダウンロード処理 |
| `launcher.sh` | 起動前の準備。Python・ffmpeg の確認、専用環境の作成、yt-dlp の自動更新 |
| `make_app.sh` / `アプリを作る.command` | `.app` を組み立てて「アプリケーション」に置く |
| `make_icon.py` | アプリのアイコンを描く |
| `test_ytdl_app.py` | テスト（`python3 -m pytest ytdl`） |

- ダウンロードは [yt-dlp](https://github.com/yt-dlp/yt-dlp)、MP3 変換と映像・音声の結合は [ffmpeg](https://ffmpeg.org/) を使っています。
  YouTube の暗号解読に必要な JavaScript 実行環境（Deno）も、yt-dlp と一緒に専用環境へ入ります。
- 画面は `127.0.0.1`（この Mac の中）からしか接続できず、ページに埋め込んだ合言葉の無い操作は受け付けません。
- 作業中のファイルは保存先の中の隠しフォルダで作り、完成したものだけを保存先に移します。
  キャンセルや失敗で中途半端なファイルが残ることはありません。
