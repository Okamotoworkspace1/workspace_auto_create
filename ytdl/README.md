# YouTube ダウンローダー（Mac 用）

YouTube の URL を貼り付けてボタンを押すだけで、**動画（MP4）** か **音声（MP3）** として保存できるツールです。

- 🎬 **MP4**：QuickTime Player や写真アプリでそのまま再生できる H.264 形式を優先して保存します
- 🎵 **MP3**：音声だけを取り出して保存します（128 / 192 / 320 kbps）
- 保存先は既定で `~/Downloads/YouTube`（画面の「保存先を変更」で変更できます）
- 完了後は「Finder で表示」ボタンを押すと、保存したファイルを Finder で表示します

> ⚠️ 著作権者が保存を認めている動画（ご自身の動画、クリエイティブ・コモンズの動画など）にだけ使ってください。
> YouTube の利用規約では、許可なくダウンロードすることを原則として禁止しています。

---

## 準備（初回だけ）

1. **Homebrew** を入れます（入っていれば不要）。 → https://brew.sh/ja/
2. ターミナルで次を実行します。

   ```bash
   brew install python ffmpeg
   ```

## 使い方

### いちばん簡単な方法：ダブルクリック

1. Finder で `ytdl` フォルダを開き、**`YouTubeダウンローダー.command`** をダブルクリックします。
   - 初回は「開発元を確認できない」と表示されることがあります。その場合はファイルを
     **右クリック（control + クリック）→「開く」** を選んでください。
   - それでも開けない場合は、ターミナルで次を実行してから、もう一度ダブルクリックしてください。
     ```bash
     chmod +x ytdl/YouTubeダウンローダー.command
     ```
2. ブラウザに操作画面が開きます。
3. URL を貼り付け、**動画 MP4 / 音声 MP3** と画質を選んで「ダウンロード」を押します。
   - URL 欄をクリックしたとき、クリップボードに YouTube の URL があれば自動で入ります（ブラウザが許可した場合のみ）。
4. 終わったら、ターミナルのウィンドウで `Ctrl + C` を押すか、ウィンドウを閉じると終了します。

初回起動時は専用の Python 環境（`ytdl/.venv`）が作られ、`yt-dlp` がインストールされます。
YouTube 側の仕様が変わるとダウンロードに失敗することがあるため、起動するたびに `yt-dlp` を最新版に更新します。

### ターミナルから直接使う

```bash
cd ytdl
./YouTubeダウンローダー.command "https://www.youtube.com/watch?v=XXXXXXXXXXX"          # MP4
./YouTubeダウンローダー.command "https://www.youtube.com/watch?v=XXXXXXXXXXX" --mp3    # MP3
./YouTubeダウンローダー.command "https://youtu.be/XXXXXXXXXXX" -q 720 -o ~/Movies      # 720p まで・保存先指定
```

| オプション | 内容 |
|---|---|
| `--mp3` | 音声だけを MP3 で保存（省略すると MP4） |
| `-q`, `--quality` | MP4: `best` / `1080` / `720` / `480`（既定 `best`）<br>MP3: `320` / `192` / `128`（既定 `192`） |
| `-o`, `--output` | 保存先フォルダ（既定 `~/Downloads/YouTube`） |
| `--port` | 画面モードのポート番号（既定は空いている番号） |
| `--no-browser` | 画面モードでブラウザを自動で開かない |

URL を付けずに起動すると、ブラウザの操作画面が開きます。

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| `ffmpeg が見つかりません` | `brew install ffmpeg` を実行してください |
| `python3 が見つかりません` | `brew install python` を実行してください |
| `ダウンロードに失敗しました: ... Sign in to confirm ...` など | `yt-dlp` が古い可能性があります。いったん終了して、もう一度起動すると最新版に更新されます |
| 再生リストの URL を貼った | `&list=...` 付きでも、表示中の動画 1 本だけを保存します |
| 最高画質の MP4 が QuickTime で再生できない | H.264 版が提供されていない動画です。VLC で再生するか、画質を下げて保存してください |

## しくみ

- ダウンロードは [yt-dlp](https://github.com/yt-dlp/yt-dlp)、MP3 変換と映像・音声の結合は [ffmpeg](https://ffmpeg.org/) を使っています。
- 操作画面は Python 標準ライブラリだけで動くローカルサーバーです。`127.0.0.1`（この Mac の中）からしか接続できません。
